# odin-recipes

## Project description

This project tests previously learned HTML content by building a simple recipe website using only HTML. It consists of a home page that links out to individual recipe pages, each showing a description, an ingredients list, and step-by-step instructions.

## Learning outcomes

- Learned the general structure of web pages and how to organize them
- Learned about various HTML elements, such as anchor tags, images, and ordered and unordered lists
- Learned about HTML boilerplate and the basic structure every HTML file follows
